# কুরআন শরীফ · Quraan Shareef (Tara)

A Bengali-first Quran reader, built as a concept redesign of quraanshareef.org (not affiliated with that site).

- **Translation mode** (`/surah/[n]`): Arabic with translations, per-ayah recitation that highlights and follows along, repeat and speed, bookmarks (the ribbon), copy.
- **Mushaf mode** (`/mushaf/[page]`): the 604-page Madani mushaf as a right-to-left book. Two-page spreads on wide screens, one page on phones. Drag a page, tap its edge, or use the arrow keys (← next, → previous).
- **Home**: continue where you stopped, jump to `2:255`, `কাহফ`, `পারা ৩০` or `পৃষ্ঠা ৪২`, juz grid, surah index.
- Six themes (চীনামাটি, মুসহাফের পাতা, পোড়ামাটি, মোগল সবুজ by day; কোবাল্ট রাত, লণ্ঠন by night). Pick one, or let a day/night pair switch at sunrise and Maghrib for your city or follow the device; separate Arabic and translation text sizes; installable and readable offline.

Design system: see [DESIGN.md](DESIGN.md). Product notes: [PRODUCT.md](PRODUCT.md).

## Run it

```bash
npm install
npm run dev
```

Production build (prerenders 114 surah pages and 604 mushaf pages):

```bash
npm run build   # static export to out/
```

## Quran data

The dataset lives in `public/data/` and `src/data/index.json` and is generated by `scripts/fetch-quran.mjs` from the alquran.cloud API:

```bash
node scripts/fetch-quran.mjs
```

- **Arabic:** Tanzil Project, two scripts fetched verbatim: Uthmani (`quran-uthmani`, the default) and Simple (`quran-simple`). Readers pick one under আরবি লিপি in settings; the choice is saved in `localStorage` and applied instantly. Surah pages carry both texts and CSS shows the chosen one; the mushaf renders the chosen one. Amiri Quran covers every character in both. Tanzil allows verbatim copying with attribution; the text must not be altered, so never edit or retype it by hand, only regenerate it with the script. The script checks that both editions stay in step ayah by ayah and that the Bismillah prefix is removed from the same 112 first ayahs in both (Tanzil's Uthmani writes it `بِّسْمِ` in surahs 95 and 97).
- **English:** Saheeh International (`en.sahih`, the default) and Abdullah Yusuf Ali (`en.yusufali`, 1934); readers pick one in settings. Saheeh International comes from Tanzil on the same non-commercial, attribution-required terms as the Bengali translations. It is the text Ibrahim Walk's recorded English audio reads, so English audio uses that recording only when Saheeh International is selected; for Yusuf Ali the device's English voice reads the on-screen text. Choose editions with `--en`, e.g. `--en en.sahih,en.yusufali`.
- **Bengali:** Muhiuddin Khan (`bn.bengali`) and Zohurul Hoque (`bn.hoque`), bundled from Tanzil via alquran.cloud. Readers pick the translator in settings. These translations are **not** public domain: Tanzil distributes them for non-commercial use with attribution, which covers this concept project. A commercial release (including ads) needs permission from the translators' publishers. To rebuild the data with them:

  ```bash
  node scripts/fetch-quran.mjs --bn bn.bengali,bn.hoque
  ```

  Running the script without `--bn` produces an Arabic + English dataset, and the app hides the Bengali options.
- **Recitation:** Arabic by Mishary Rashid Alafasy and English by Ibrahim Walk, streamed per ayah from the Islamic Network CDN. Check its terms before caching audio for offline use. Bengali is read by the device's Bengali voice where one is installed.

### Word by word (শব্দে শব্দে)

Each surah page has an আয়াত | শব্দে শব্দে switch (remembered like other settings). In word view every word shows its Arabic (following the Uthmani / Simple setting), a Latin transliteration (toggle: উচ্চারণ in settings), and its Bengali and English meanings (following the translation toggles); tapping a word plays its recording.

- **Data:** `node scripts/fetch-wbw.mjs` writes `public/data/wbw/<surah>.json` (committed, about 7 MB, 77,429 words) from the Quran.com API v4, verbatim: Uthmani and Imlaei word text, Bengali and English word meanings, transliteration. The script checks ayah order, word positions and languages against the Quran index. A surah's file is fetched only when a reader switches to word view.
- **Audio:** word recordings stream from Quran.com's CDN (`audio.qurancdn.com/wbw/…`).
- Word text follows Quran.com's own encoding, so it can differ in small spelling details from the Tanzil text used in ayah view. Check Quran.com's terms before any commercial use.

### Ayah explanations (ব্যাখ্যা)

Every ayah has an explain button that opens recognised tafsir, not AI-generated text:

- **Plain explanation:** Al-Mukhtasar fi al-Tafsir (Tafsir Center for Quranic Studies), in Bengali or English.
- **Detailed tafsir:** Tafsir Ahsanul Bayaan (Bengali) or Tafsir Ibn Kathir, abridged (English).

The text comes from the [spa5k/tafsir_api](https://github.com/spa5k/tafsir_api) collection, pinned to one commit in `src/lib/tafsir.ts`. `node scripts/fetch-tafsir.mjs` copies that commit's texts verbatim into `public/data/tafsir/` (one file per ayah, about 64 MB, not committed); the Pages workflow runs it before every build, so explanations load from the site itself. The panel prefetches the neighbouring ayahs and the other depth, and falls back to jsDelivr when a local file is missing (for example in `npm run dev` before running the script). Opened explanations are cached offline. That repo's MIT licence covers its code only; the tafsir texts belong to their authors and publishers and are distributed via Tarteel's Quranic Universal Library and quran.com. The panel credits and links each source. For commercial use, get the publishers' permission or use the official Quran Foundation API with registered credentials.

Before any public launch, verify the Arabic against an authoritative source and keep the attributions in the footer.

## Structure

```
src/app/            routes: home, surah/[n], mushaf/[page], manifest, icon
src/components/     Mosaic (canvas chini-tikri), MushafBook, MushafPage, SurahReader, settings, home cards
src/lib/            data access, numerals, local storage, theme script (sun-following)
scripts/            dataset builder and Bengali surah names
public/sw.js        offline cache for pages, assets and Quran data
```

Reading position, bookmarks and settings are stored in `localStorage` on the device.
